# Админка QURAL-SAIMAN

Next.js 15 (App Router) + Supabase. Управление каталогом: инструменты, категории, ДГУ, акция, фото, иконки, настройки сайта. Без TypeScript и SCSS — чтобы код мог читать и править не только автор.

## Запуск

База должна быть готова — см. `db/README.md` в основном проекте (schema.sql + seed.sql + бакет `tools` + запись в `admins`), плюс миграции из `db/migration-*.sql`.

```bash
npm install
cp .env.example .env.local
```

Открыть `.env.local` и подставить значения:

| Переменная | Где взять |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Project Settings → Data API → API URL, **без** `/rest/v1/` |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Project Settings → API Keys → Publishable key (`sb_publishable_…`) |
| `NEXT_PUBLIC_SITE_URL` | Адрес сайта без слэша. Необязательно, по умолчанию `https://qural-saiman.pages.dev` |

```bash
npm run dev
```

Открыть http://localhost:3000 — редирект на `/login`, войти под email и паролем из Authentication.

## Деплой на Vercel

1. Залить папку в репозиторий (отдельный репо или подпапка с Root Directory = `nextjs-admin`)
2. [vercel.com](https://vercel.com) → Add New Project → выбрать репозиторий
3. Environment Variables — добавить переменные из таблицы выше
4. Deploy

Рабочий адрес: `qural-saiman-admin.vercel.app`. На него завязаны сайт (`qs-catalog.js` берёт каталог) и `robots.txt` (карта сайта) — при смене адреса поправить оба.

## Структура

```
app/
  actions.js          все мутации (server actions), проверка сессии + RLS
  login/              вход
  tools/              инструменты: таблица, фильтры, порядок, форма
  categories/         семейства и категории, drag-сортировка, иконки
  dgu/                генераторы
  pricing/            акция 5+1, правила расчёта (вышки, леса)
  media/              фото: массовая загрузка, «нужны фото»
  settings/           контакты, соцсети, SEO, смена пароля
  api/catalog/        публичный JSON каталога для сайта
  api/sitemap/        карта сайта из базы
components/           Shell, Sidebar, Drawer, Toast, Toggle, IconPicker, PhotoField
lib/
  supabase/           клиенты для браузера, сервера и middleware
  data.js             чтение данных для страниц
  format.js           формат цен, склонения, ссылки на фото
  upload.js           загрузка фото и иконок в Storage
  site.js             адрес публичного сайта
middleware.js         защита роутов, обновление сессии
```

## Как это работает

**Доступ.** `middleware.js` не пускает дальше `/login` без сессии. Запись в базу разрешена только тем, кто есть в таблице `admins` — проверка на стороне Postgres (RLS), не в коде. Даже с publishable-ключом изменить каталог нельзя.

**Мутации.** Все через server actions в `app/actions.js`; после сохранения `revalidatePath` перерисовывает страницу.

**Связь с сайтом.** Сайт статический (Cloudflare Pages) и при загрузке берёт каталог из `/api/catalog`. Правка в админке появляется на сайте в пределах нескольких минут (кэш API + кэш браузера). Если API недоступен — сайт показывает встроенный снимок из `tools-data.js`.

**Карта сайта.** `/api/sitemap` собирает XML из опубликованных инструментов, кэш на час. `robots.txt` сайта ссылается на неё — отдельно отправлять в Search Console не нужно. Файл `sitemap.xml` в папке сайта — устаревший запасной вариант, на него никто не ссылается.

**Фото.** Загружаются напрямую в бакет `tools`, имя файла = артикул позиции, путь пишется в `photo_path`. Замена с тем же именем перезаписывает старый файл.

**Иконки категорий.** Два режима: глиф из набора lucide (поле `icon`) или свой SVG (поле `icon_url`, файл в `tools/icons/`). Своя иконка имеет приоритет. SVG должен быть одноцветным — сайт перекрашивает его маской под тему, растровые картинки не подходят.

**Порядок.** `sort` считается внутри категории. В режиме «Порядок» нужно сначала выбрать категорию — иначе перетаскивать нечего.

**KZ.** Поля `*_kz` есть в формах, интерфейс админки только на русском. Пустое KZ-поле означает «показывать русское». На сайте переключатель языка пока не подключён.

## Чего здесь нет

- **Наличия.** Остатки ведутся в 1С и на сайт не выводятся.
- **Заявок.** Клиент пишет в WhatsApp, переписка живёт там.
- **Процентных скидок.** Единственная акция — 5+1, только бензо- и электроинструмент.
- **Ролей.** Все, кто в `admins`, имеют полный доступ.

## Если купите домен

1. Vercel → Environment Variables → `NEXT_PUBLIC_SITE_URL` = новый адрес → Redeploy
2. На сайте: canonical / OG во всех HTML и строка `Sitemap:` в `robots.txt`
